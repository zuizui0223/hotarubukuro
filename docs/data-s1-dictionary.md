# Data_S1.csv — public data dictionary

`Data_S1.csv` is the distributable observation/trait table used as the public phenotype/source layer of the paper. It is generated by `source_build/build_data_s1.py` from a verified colour-extraction table.

The export is designed to preserve scientific provenance while excluding local filesystem paths, QC-image paths and raw activity URLs that are unnecessary for reproducibility and could increase linkage risk.

## Unit of observation

One row represents one screened photographic observation in the public trait/source table.

The final environment-complete ecological analysis uses 1,922 observations; `Data_S1.csv` can contain rows that are later excluded by exact-duplicate or environmental/raster-support criteria. Those ecological analysis filters are applied downstream and are documented in the manuscript/SI and analysis workflows.

## Guaranteed public identity and provenance columns

| Column | Meaning |
|---|---|
| `observation_id` | Unique study observation identifier. |
| `source_row` | Unique row identifier inherited from the verified source/extraction table. |
| `photo_id` | Source photo identifier used during image/QC processing. |
| `image_sha256` | SHA-256 digest of the source image bytes used for duplicate/provenance auditing. |
| `duplicate_image_sha256` | Duplicate-image flag when the same image digest occurs more than once in the verified extraction input. |
| `date` | Calendar date normalized to ISO `YYYY-MM-DD`. |
| `latitude` | Latitude carried from the verified source workbook, in assumed EPSG:4326. |
| `longitude` | Longitude carried from the verified source workbook, in assumed EPSG:4326. |

## Coordinate and site-provenance columns

| Column | Meaning |
|---|---|
| `source_reference_type` | Coarse source category; YAMAP activity-linked records are labelled `yamap_activity`, otherwise `field_survey_or_other`. |
| `coordinate_source` | Provenance of the public coordinates. Current export uses `source_workbook`. |
| `coordinate_crs_assumed` | Coordinate reference system assumed for source latitude/longitude; current export uses `EPSG:4326`. |
| `coordinate_recomputed` | Whether public coordinates were newly recomputed during `Data_S1` construction. Current export is `False`. |
| `coordinate_qc_status` | Explicit coordinate-QC status; the current export states that source values were not independently recomputed. |
| `photo_coordinate_qc_status` | Photo/location linkage status derived from workbook-cell and image-hash provenance, with duplicate-photo cases flagged for review. |
| `exact_site_id` | Stable privacy-neutral exact-coordinate site identifier generated by hashing latitude/longitude rounded to 10 decimal places. |
| `grid_30s_id` | Deterministic global 30-arc-second grid-cell identifier anchored in EPSG:4326. |

`exact_site_id` is an analysis identifier, not a biological population identifier.

## Colour and image-measurement columns

The verified colour extraction supplies the following required fields, which are retained publicly unless explicitly excluded for privacy/path reasons:

| Column | Meaning |
|---|---|
| `median_R`, `median_G`, `median_B` | Median source-image RGB measurements used in the verified extraction/QC pipeline. Values are constrained to 0–255. |
| `R`, `G`, `B` | Primary RGB colour measurements used by the extraction result. Values are constrained to 0–255. |
| `primary_colour_method` | Name/label of the colour-extraction method selected as primary for the row. |
| `extraction_version` | Version identifier of the extraction pipeline. |
| `qc_status` | Automated/verified extraction QC status carried into the public table. |
| `colour_measurement_scope` | Measurement-scale declaration. Current public export uses `uncalibrated_display_referred_sRGB`. |
| `manual_review_status` | Whether automated QC requires additional manual review. |

Additional non-path extraction/QC columns present in the verified source table are preserved in `Data_S1.csv`. The exact machine-readable header of the distributed file is therefore the authoritative list for a given release.

## Important interpretation limits

- RGB/CIELAB values are image-derived visible-colour measurements, not spectrometer reflectance.
- They are not direct anthocyanin concentrations or UV measurements.
- Coordinates are carried from the verified source workbook; `Data_S1` construction does not claim to re-georeference them from GPX.
- `exact_site_id` and grid IDs are computational grouping variables, not evidence of genetic populations.
- Original YAMAP photographs and raw activity URLs are not redistributed in this repository.

## Columns intentionally excluded from the public export

`source_build/build_data_s1.py` explicitly excludes local/private processing references including:

- `source_path`;
- `mask_path`;
- `overlay_path`;
- `qc_panel_path`;
- raw `url`.

These exclusions do not affect the numerical trait measurements used by the analysis.

## Programmatic validation

`source_build/build_data_s1.py` validates, among other things:

- unique, non-empty `observation_id`;
- unique `source_row`;
- geographic coordinate bounds;
- finite RGB values within 0–255;
- lowercase 64-character SHA-256 image digests;
- non-empty input rows and unique headers.

To inspect the exact columns in a checked-out release:

```bash
python - <<'PY'
import csv
with open('Data_S1.csv', newline='', encoding='utf-8-sig') as f:
    print('\n'.join(next(csv.reader(f))))
PY
```

## Rebuilding the public table

The builder is:

```bash
python source_build/build_data_s1.py --help
```

The extraction input itself may contain third-party/local provenance that is not suitable for redistribution. Rebuilding from raw photographs therefore requires lawful access to the original image material; reproducing the published ecological analysis starts from the distributed `Data_S1.csv`.
