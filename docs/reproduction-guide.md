# Reproducing the current manuscript-facing analyses

Start with [`../paper/README.md`](../paper/README.md), [`../paper/analysis-map.md`](../paper/analysis-map.md) and `../reproducibility/final_integrated_pipeline_2026-08-12.md`. They define the current scientific hierarchy, executable routes and checksum-locked evidence used by the JBI manuscript.

The current paper is **not** reproduced by the historical 1,909 architecture or by the former current-input workflow that continued into four-PC matching and 17 local-departure candidates. Those execution paths are preserved under `legacy/` for provenance.

## Current analysis chain

1. **YAMAP / iEcology** — curated source frame, image audit and two-part quantitative flower-colour phenotype.
2. **Main 1: final Broad** — response-specific eight-axis environment + stationary INLA-SPDE; state additive, conditional intensity with Temperature PC1 × temperature-seasonality.
3. **Main 2: local focal Bombus** — Bombus/environment-blind sharp nearby white-pigmented transitions versus occurrence-referenced *B. ardens* + *B. diversus* habitat support.
4. **Main 3: current-Broad local departures** — final-eight-axis local matching, 10,000-map replay under the locked cross-fitted state reference, then post-selection human-context maxT characterization.

Five-species Bombus turnover and montane/elevation comparisons are Supporting guardrails, not additional Main mechanisms.

## Local execution

A full local rebuild is not the preferred manuscript audit route because the final evidence chain deliberately pins large raster-derived and predictive-draw artifacts. For development, restore the declared environment first:

```bash
Rscript scripts/setup_r_environment.R \
  --report-dir reproducibility \
  --scopes analysis,reproducibility,acquisition,testing,figures,reporting
```

Then use only scripts and workflows listed in `paper/active-file-map.csv`. Do not use files under `legacy/` as manuscript-facing entry points.

## Data and source-build boundary

- `Data_S1.csv` is the curated derived trait/source table distributed with the repository.
- Original YAMAP photographs are third-party material and are not redistributed.
- `source_build/` contains current source-construction utilities for visible colour, environmental inputs, Bombus occurrences/SDMs and human rasters.
- Live external services can change; acquisition refreshes are new analyses and must not silently replace frozen manuscript artifacts.

The former `inputs/canonical_snapshot.json` / `scripts/canonical_snapshot.sh` restorer is no longer required by the current human workflow because static support is restored directly from checksum-locked artifacts. ## Statistical rather than accidental reproducibility

The manuscript locks input identities, seeds, model/event definitions, artifact hashes and claim ceilings. INLA draws and live public-data retrievals need not be bitwise identical across platforms or dates. Any refreshed source or changed model definition is treated as a new analysis rather than silently substituted for the frozen evidence.
