# Local colour-state asymmetry diagnostic

This archived diagnostic compares pigmented-in-white and white-in-pigmented local events. Its runner described it as post hoc, and it is not one of the ordered manuscript aims.

It is retained with its R module, validator and unit test for provenance. It is absent from `R/pipeline_support.R`, `scripts/run_publication_pipeline.R`, the stage registry and the final claim lock.
