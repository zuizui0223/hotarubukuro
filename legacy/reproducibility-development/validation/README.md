# Archived result-identity audits

These files are preserved for provenance and are not current acceptance criteria.

- `audit_phenotype.R` and `audit_multiscale_hotspots.R` audit the historical v11/v15 publication boundary, including published-population identities and superseded national Bombus/fingerprint outputs.
- `audit_human_landscape_features.R` converts particular historical inferential findings into PASS/FAIL conditions rather than separating structural validation from reconstruction-specific results.

The current reconstruction uses the independent validators and reconstruction-aware claim audits that remain under the top-level `validation/` directory. Do not invoke the files in this directory from current workflows.
