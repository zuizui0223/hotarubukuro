# Superseded source-build prototypes

This directory contains source-build utilities that were useful during method development but are not used by the current paper-facing workflows.

Current Bombus source build:

- `source_build/build_bombus_sdm_mainland.R`
- `.github/workflows/rebuild-bombus-sdm.yml`

Archived here:

- earlier species-specific / national-projection Bombus builders;
- standalone population-flow audits no longer required by the current pipeline;
- validation scripts tied only to those superseded projections.

These files are provenance only. Do not infer current manuscript methods from this directory.
