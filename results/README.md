# Generated results

The repository does not treat committed `results/` tables as manuscript evidence. Current numerical claims are reproduced in GitHub Actions and tied to frozen run/artifact/checksum records in `paper/analysis-map.md`.

Use these manuscript-facing routes:

- broad natural template + anomaly/human context: `.github/workflows/reanalysis-current-inputs.yml`;
- local focal-Bombus availability: `.github/workflows/bombus-local-sharp-transition.yml`;
- supplementary Bombus boundary / montane guardrails: `.github/workflows/bombus-spatial-replication-test.yml`;
- integrated manuscript audit: `.github/workflows/final-paper-analysis.yml`.

Generated outputs remain workflow artifacts unless a small derived table is deliberately promoted into `submission/jbi/supporting/` or a reproducibility note.

Historical committed 1,923 results and superseded pipeline products are under `legacy/`.
