# Generated JBI delivery bundle

The repository stores manuscript sources, builders, validators and checksum locks. Editable delivery files are generated by `.github/workflows/jbi-submission-bundle.yml` rather than committed as opaque Word/PDF archives.

The generated package contains:

- one anonymized Main DOCX with Figure 1–4 legends and embedded PNGs;
- one combined editable Supporting Information DOCX containing Appendices S1–S6;
- separate title-page and cover-letter DOCX templates;
- an optional Japanese translated-abstract DOCX;
- a current Bombus SDM/model-building checklist DOCX;
- four separate 600-dpi PNG and four vector PDF Main figures;
- a file/SHA-256 manifest;
- a machine-readable readiness report;
- explicit placeholders for the required taxon image and private-for-peer-review data/code URL.

`review_science_bundle_complete=true` means the anonymous scientific materials were assembled and structurally validated. It does **not** mean the portal package can be submitted. `portal_ready` remains false until the authors complete and approve authorship, affiliations, ORCIDs, corresponding-author details, acknowledgements, funding, conflict of interest, author contributions, the cover-letter signature, the private review repository link, the taxon image and any required AI-use disclosure.

Every generated DOCX is converted through LibreOffice in CI. Final human visual review is still required because portal upload, co-author approval and disclosure decisions cannot be automated.
